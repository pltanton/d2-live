# Edit Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An edit mode in the d2-live preview tab: CodeMirror side editor with autosave, diagram ↔ code selection, inspector and on-node controls whose structural ops land as minimal byte splices in the `.d2` file.

**Architecture:** Go server compiles the file with `d2compiler`, serves a model (objects/edges/classes with UTF-16 ranges) and applies ops as byte splices computed from AST ranges; the browser applies returned text to CodeMirror as one transaction and autosaves through an atomic `PUT /source`. The file stays the source of truth; SSE pushes external changes.

**Tech Stack:** Go 1.25, `oss.terrastruct.com/d2` (master `716f6185da68`: d2compiler, d2graph, d2ast), fsnotify; CodeMirror 6 ES modules from jsdelivr; panzoom (already used). No frontend build.

Spec: `docs/superpowers/specs/2026-10-06-edit-mode-design.md`.

## Task 2: source.go — hashing, atomic writes, echo suppression

Interfaces:

```go
func contentHash(b []byte) string                       // hex sha256
func writeAtomic(path string, data []byte) error        // tmp in same dir + rename, keeps mode
func (s *server) markWritten(abs, hash string)          // remembered per file
func (s *server) isOwnWrite(abs, hash string) bool      // consumes the mark
```

Event channel changes from `chan struct{}` to `chan event{kind string}`:
`reload` (as today) and `source` (only when the content hash differs from the
last write by us). `scheduleRerender` reads the file, compares with
`isOwnWrite`, sends `source` (+ always `reload`).

HTTP:

- `GET /source?file=` → `{"text","hash"}`; 403 unless registered.
- `PUT /source` `{"file","baseHash","text"}` → 409 `{"reason":"stale","text","hash"}` when disk hash ≠ base; 403 unregistered; 200 `{"hash"}`.

Tests (`source_test.go`, using `httptest` + a temp dir server):

- write then read back, file mode preserved;
- stale base → 409 with current text;
- unregistered path → 403;
- own write produces `reload` but not `source`; an external `os.WriteFile` produces both.

Commit `feat: source endpoints with atomic writes and echo suppression`.

## Task 3: model.go

```go
type span struct{ From, To int }                         // UTF-16 offsets
type comment struct{ Text string; Range span }
type objectModel struct { ID, Label string; Markdown bool; Class, Shape string;
  Style map[string]string; Decl span; Refs []span; Comment *comment }
type edgeModel struct { ID, Src, Dst, Label, Class string; Style map[string]string;
  Decl span; Comment *comment }
type classModel struct { Name string; Style map[string]string; Shape string; Decl span }
type compileError struct{ Line, Col int; Message string }
type Model struct { Hash string; Objects []objectModel; Edges []edgeModel;
  Classes []classModel; Error *compileError }

func buildModel(text []byte) Model
```

Rules: top-level objects only (`obj.Parent == g.Root`, skipping none — `title`
and `notes` included), `decl` = first reference whose `MapKey.Key` is the
object's own key (not an edge end), or the first reference; `refs` = the rest
(range of `ref.Key.Path[ref.KeyPathIndex]`). Comment run = consecutive
`# …` lines immediately above the decl line (no blank line), via the root map's
`Comment` nodes. Compile error → parse `d2compiler` error text `x.d2:LINE:COL: msg`.

Tests: on `testdata/withdraw-fsm.d2` — `DECISION_APPROVED` decl text equals the
declaration line slice, has 2 refs; edge `(INTAKE_STARTED -> REJECTED)[0]` has a
comment starting with `A refused hold`; `classes` contains `pause` with fill
`#FFF8E8`; `title` is markdown; broken input gives `Error.Line`.

Commit `feat: diagram model endpoint`.

## Task 4: edit.go — splice engine and ops

```go
type splice struct{ from, to int; text string }   // byte offsets
func applySplices(src string, ss []splice) string // sorted desc, non-overlapping
type op struct { Kind, ID, To, Key string; Value *string; Text, Src, Dst, Label, Class, EdgeClass string }
func applyOp(src string, o op) (out string, selectID string, err error)
type opError struct{ Field, Message string }      // → 422
```

Ops and golden cases (input `testdata/withdraw-fsm.d2`, output
`testdata/golden/<case>.d2`, compared byte-for-byte; regenerate with
`go test -run TestOps -update` and review the diffs by hand):

| case                                              | op                                                                                                  |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| rename                                            | `rename DECISION_APPROVED → APPROVED`                                                               |
| rename_conflict                                   | `rename DECISION_APPROVED → COMPLETED` → opError field `to`                                         |
| set_node_class                                    | `set DECISION_APPROVED class pause`                                                                 |
| set_edge_class                                    | `set (FINALIZING_COMMIT -> COMPLETED)[0] class evt` (no duplicate)                                  |
| set_edge_label_new                                | `set (DECISION_APPROVED -> FINALIZING_SEND_PENDING)[0] label "go"`                                  |
| set_node_label_quoted                             | `set SCREENING_AML_PENDING label "a\nb"`                                                            |
| set_title_md                                      | `set title label "# New"` stays `                                                                   | md` |
| set_class_style                                   | `set classes.pause style.fill #FFF0C0` inside `classes:` block                                      |
| set_style_new_key                                 | `set INTAKE_STARTED style.fill #fff` → `{class: active; style.fill: "#fff"}`                        |
| unset_class                                       | `set COMPLETED class null` → `COMPLETED` (empty `{}` gone)                                          |
| comment_replace / comment_insert / comment_remove | `setComment` on edges with/without a run                                                            |
| create_node                                       | `createNode class=pause` after `REJECTED: {class: done_bad}`                                        |
| create_edge                                       | `createEdge FINALIZING_COMMIT → REJECTED label x class evt` after `FINALIZING_COMMIT -> COMPLETED…` |
| create_node_with_edge                             | from `DECISION_APPROVED`                                                                            |
| delete_node                                       | `DECISION_REJECTED` — decl line + 2 edges + their comments, no doubled blank lines                  |
| delete_edge                                       | `(INTAKE_STARTED -> REJECTED)[0]` with its 3-line comment                                           |
| reverse                                           | `(FINALIZING_CANCEL -> REJECTED)[0]`                                                                |
| chain_rejected                                    | input `a -> b -> c`, `rename b` → opError                                                           |

Every op compiles its output; compile failure → opError.

Commit after each group (rename; set; comments; create; delete/reverse).
